MAS

Phần mềm quản lý bán hàng cho cửa hàng. Tải về và cài, dùng được khi mất mạng.

Bạn đang mở trong ứng dụng khác (Zalo, Facebook…). Hãy bấm nút Sao chép đường dẫn bên dưới rồi dán vào Safari hoặc Chrome để cài được.

iPhone, iPadDành cho máy của bạn

Cài từ web, không cần App Store. Dùng trình duyệt Safari.

  1. Mở trang này bằng Safari.
  2. Bấm nút Chia sẻ (ô vuông có mũi tên lên) ở thanh dưới.
  3. Kéo menu lên, chọn Thêm vào MH chính, rồi bấm Thêm.
  4. Mở biểu tượng MAS ở màn hình chính.

Mở MAS thử

Hoặc cài app thật bằng file (không qua Safari)

Cần một máy tính (Windows hoặc Mac) và Apple ID miễn phí. App cài kiểu này hết hạn sau 7 ngày và phải cài lại bằng cùng cách.

  1. Tải file MAS-iPhone.ipa về máy tính.
  2. Cài phần mềm miễn phí Sideloadly (hoặc AltStore) trên máy tính.
  3. Cắm iPhone vào máy tính, kéo file .ipa vào Sideloadly, nhập Apple ID, bấm Start.
  4. Trên iPhone: Cài đặt, Cài đặt chung, VPN và quản lý thiết bị, chọn Apple ID của bạn, bấm Tin cậy. Từ iOS 16 còn phải bật Chế độ nhà phát triển trong Quyền riêng tư và bảo mật.

Android, máy POS AndroidDành cho máy của bạn

Cách tốt nhất: cài từ Chrome, có in bill và lưu file đầy đủ.

Nếu nút chưa cài được: mở bằng Chrome, bấm ba chấm, chọn Cài đặt ứng dụng.

Tải file APK

File APK: máy sẽ hỏi cho phép cài từ nguồn này, hãy đồng ý. Bản APK chưa hỗ trợ in bill.

Windows, máy POS WindowsDành cho máy của bạn

Tải file cài đặt rồi bấm đúp.

Nếu hiện “Windows đã bảo vệ PC của bạn”: bấm Thông tin thêm, rồi Vẫn chạy.

MacDành cho máy của bạn
